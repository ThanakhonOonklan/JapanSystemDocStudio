# วิธีเขียน {#writing}

บทนี้สรุปรูปแบบที่ใช้บ่อย ดูภาพรวมของโปรเจกต์ได้ใน @intro

## หัวข้อ {#headings}

ใช้เครื่องหมาย `#` เพื่อทำหัวข้อ ระบบใส่เลขให้เอง เช่น 2.1 และ 2.1.1 ถ้าไม่ต้องการเลข ให้ใส่ `{.unnumbered}` ท้ายหัวข้อ

ใส่รหัสท้ายหัวข้อด้วย `{#รหัส}` เพื่อให้ที่อื่นอ้างถึงได้ด้วย `@รหัส` เช่น หัวข้อนี้อ้างถึงด้วย @headings

## รูปภาพ {#images}

รูปที่อยู่บรรทัดของตัวเองและมีคำอธิบายจะได้เลขรูปอัตโนมัติ:

```markdown
![คำอธิบายรูป](../assets/ชื่อรูป.png){#fig-ตัวอย่าง width=60%}
```

## ตาราง {#tables}

เขียนคำอธิบายตารางในบรรทัดถัดจากตาราง โดยขึ้นต้นด้วยเครื่องหมายทวิภาค:

```markdown
| ก | ข |
|---|---|
| 1 | 2 |

: คำอธิบายตาราง {#tbl-ตัวอย่าง}
```

## อีกภาษาหนึ่ง {#other-language}

ไฟล์ในโฟลเดอร์ `en/` ควรมีหัวข้อ รูป และตารางที่ใช้รหัส `{#...}` ชุดเดียวกัน เพื่อให้สองภาษาตรงกัน
