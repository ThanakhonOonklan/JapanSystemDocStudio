# Contributing to Japan Documentation Studio

Thank you for helping. Here are some notes on how to report a bug or send a change.

## Reporting bugs and opening issues

Describe the issue as clearly as possible: how to reproduce it, where it
appears, what you expected to happen and what actually happens. A screenshot
helps for problems in the user interface.

## Pull requests

See the README for how to build and run the system. Keep each pull request to
one change and describe what it does and how you checked it.

## Security

Report a potential security problem to the maintainers privately, not in a
public issue.
